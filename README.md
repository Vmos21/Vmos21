## 🙋‍♂️ About Me

I'm a second-year **B.E. Computer Science** student at **PSG College of Technology**, Coimbatore. I love building things end-to-end — whether that's a full-stack web app, a CLI tool that runs LLMs from scratch, or an encrypted messaging device on an ESP32.

- 🌱 **I'm currently learning** — Embedded systems with ESP32, and grinding DSA patterns in C/C++.
- 🔐 **Side quest** — Exploring ethical hacking and cybersecurity.
- ⚡ **Fun fact** — I'm building a terminal-based world domination game in C++ called [the_world_2](https://github.com/Vmos21/the_world_2). Yes, really.

## 🚀 Featured Projects

| Project | Description | Stack |
|:--------|:------------|:------|
| [**ConfigForge**](https://github.com/Vmos21/ConfigForge) | Converts JSON/YAML config files into visual drag-and-drop forms — deployed and usable as a standalone tool or embeddable widget | React, Vite, Supabase, Vercel |
| [**TableWeave**](https://github.com/Vmos21/TableWeave) | Upload `.sql` → interactive ER diagram with auto-layout, draggable nodes, and Bezier FK lines | React, TypeScript, Express, node-sql-parser |
